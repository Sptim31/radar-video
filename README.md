# Radar Vidéo France

**Ouvrir le site : https://sptim31.github.io/radar-video/**

Carte de France avec des bulles par ville : chaque bulle indique le nombre de vidéos YouTube du jour et du sujet choisis.
Clique une bulle pour voir les vidéos de la ville et les lire dans la page.

- Première ouverture : colle une clé YouTube Data API v3 (gratuite), elle reste dans ton navigateur.
- `communes.json` : ~18 000 communes (population ≥ 400) avec coordonnées, pour repérer les villes citées dans les titres.
- `serveur-youtube/` : ancienne version avec serveur Python.
